# CmdPalm Homebrew tap

The CmdPalm project's Homebrew cask for [CmdPalm](https://cmdpalm.app), the Mac app that turns your phone into a trackpad, keyboard and button deck.

Requires an Apple Silicon Mac running macOS 15 or later.

```sh
brew install --cask rahatsagor/tap/cmdpalm
```

CmdPalm is self-signed and is not notarized by Apple. This cask removes quarantine from the installed CmdPalm app bundle. Allow Accessibility access in System Settings when CmdPalm asks for it.

The recipe is updated with each CmdPalm release. Source and downloads are available in [rahatsagor/CmdPalm](https://github.com/rahatsagor/CmdPalm).
